# Maquettes de la prochaine interface

Ces fichiers présentent les propositions discutées avec l’officine. Ils
contiennent uniquement des interactions locales et des données fictives.
Ils ne sont pas reliés à Streamlit, aux fichiers patients ou à la CAFAT.
Ils n’envoient aucun mail et ne réalisent aucun encaissement.

| Fichier | Parcours présenté |
| --- | --- |
| [01-interface.html](01-interface.html) | Les quatre espaces, dans un habillage vert et sauge. |
| [02-locations-achats.html](02-locations-achats.html) | Préparation des périodes et achat privilégié du fauteuil. |
| [03-equipe-et-retours.html](03-equipe-et-retours.html) | Initiateur d’entente, renouvellement, retour de matériel et restitution de caution. |
| [04-prise-en-charge-caution.html](04-prise-en-charge-caution.html) | Remboursement à vérifier par dossier, cautions de 5 000 / 3 000 F CFP et choix chèque / espèces. |

Les fichiers HTML peuvent être ouverts localement dans un navigateur.
Les emplacements d’icônes peuvent rester vides hors de l’environnement
d’aperçu ; les commandes utilisent aussi des libellés textuels. Les loyers
illustratifs ne sont pas des tarifs CAFAT. Les montants de caution de
l’aérosol et du tensiomètre proviennent des instructions de l’officine.

Le [cahier des charges](../proposition-locations-cafat.md) est la référence
fonctionnelle, notamment pour les règles non simulées : régularisations,
droits, transitions réglementaires, contrats, planning et rappel mail.

La version 6.35 ne déploie pas ces maquettes dans l’application. Elle
livre les corrections de fiabilité du module Location.
